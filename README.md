# Last Run

A first-person ski game for the browser. Four friends ride the last lift of New Year's Eve, a
storm rolls in, and you pick one last run before the after-ski: the kids' slope, the snow park,
the slalom, the black downhill or the off-piste maze. Built with Unity 6 (WebGL).

## Play it

https://augustfricking.github.io/new-years-ski-game/ (a desktop browser with a keyboard and mouse)

## Play it locally
The web build is in `SkiGame/Builds/WebGL` (not in git; build it from the Editor or with the
steps below). Serve that folder with any static web server and open it in a browser:

```bash
python -m http.server 8123 --directory SkiGame/Builds/WebGL
```

Then open http://localhost:8123.

## Controls
| Key | Action |
|---|---|
| A / D | Turn. A short hold carves and gains speed; a long hold skids and brakes. |
| W | Hold to tuck: faster, but turns less |
| S | Snowplough brake |
| Left click | Pole push at low speed: click when the dot is in the green at the top of the ring |
| C | Switch between first and third person |
| Space | Jump |
| 1 2 4 | Grabs in the air (add W or S for variants) |
| 3 | Flip (S or nothing = backflip, W = frontflip) |
| 5 | Cork |
| A / D in the air | Spin; let go to land straight |
| Mouse | Look around (click the game first; or hold the right button) |
| R | Back on course |
| Esc | Pause and settings |

In the tavern: W A S D to walk, mouse to look, E to use, Space to gulp.

## The skiers
| Who | Gear | Trait |
|---|---|---|
| Jonte | snowboard | slightly higher top speed in a tuck |
| Maja | skiblades | tighter turns that lose less speed, lower top speed |
| Erik | carving skis | gains more speed from a clean carve |
| Linn | twin-tips | easier push timing and stronger pushes |

## World boards and ghosts

Every result is kept on this device. The game also signs in anonymously to Unity Gaming Services
(free tier, no account): one profile per browser or device, with the name set under Settings.
Other players' best runs then appear on the results card and as ghosts on the slope.

Boards and ghosts hold real people only: there are no computer rivals. The six boards
(`slope_green`, `slope_blue`, `slope_red`, `slope_black`, `slope_offpiste`, `chug`) live in the
Unity cloud project; their settings are also kept as files in `SkiGame/Assets/_Game/Cloud`.

In the tavern, left click throws a punch.
